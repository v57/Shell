# Keyboard Shortcuts

## Shell menu (Mac)

| Keys | Command |
|---|---|
| ⌘N | **New Local Terminal**. With something selected, a new one of the same kind: **New Connection to …**, **New Persistent Session**, **New Web Page** or **New Note** |
| ⌘T | **New Terminal in Same Directory** |
| ⇧⌘N | **New Persistent Session** |
| ⌘R | **Actions…** (the actions palette) |
| ⇧⌘R | **Create Action from Session** |
| ⌘E | **Insert into Terminal…** |
| ⇧⌘D | **Detach Session/Note** (again to bring it back) |
| ⇧⌘H | **Appearance…** |
| ⇧⌘F | **Toggle Files Panel** |
| ⇧⌘U | **Navigate Up** in the Files panel |
| ⌘W | **Close Terminal**, **Close Connection**, **Close Session**, **Close Note** and so on, for the selected item. It never closes the main window. |
| ⇧⌘C | **Copy SSH Public Key** |
| ⌘, | **Settings…** |

A command whose feature is off in **Settings ▸ Features** is left out of the menu, along with its shortcut.

## Data menu (Mac)

With **Database** on, the **Data** menu has Database's commands for the open database:

| Keys | Command |
|---|---|
| ⌥⌘T | **New Query** |
| ⌥⌘R | **Refresh** |
| ⌘Return | **Run** |
| ⇧⌘E | **Show Query Editor** / **Hide Query Editor** |
| ⌘S | **Review Changes…** |
| ⌥⌘I | **Show Inspector** |
| ⌥⇧⌘Z | **Undo Last Save** (in the Edit menu) |

## In a terminal

On the Mac, and on iPad with a hardware keyboard:

| Keys | What it does |
|---|---|
| ⌘C | Copy the selection, or the visible screen when nothing is selected |
| ⌘V | Paste |
| ⌘K | Clear the scrollback |

Every other key, with Control and Option, goes to the program in the terminal.

## Everywhere

| Keys | What it does |
|---|---|
| ⌃⌘1 … ⌃⌘9 | Switch to the first to ninth account (Mac, and iPad with a keyboard) |
| ↑ ↓, Return, Esc | Move, run and close in the actions palette |
| Return | The main button of a sheet (**Connect**, **Save**, **Create**, **Add**, **Apply**) |
| Esc | Cancel a sheet; close Settings on iPad |

On iPad, Shell has no menu commands: use the buttons, row menus and **Settings ▸ Actions** instead.
