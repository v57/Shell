# Keyboard Shortcuts

The menu commands are on the Mac, Linux and Windows. On iPhone and iPad, Shell has no menu commands: use the
buttons, row menus and **Settings ▸ Actions** instead.

## Everywhere

| Keys | What it does |
|---|---|
| ↑ ↓, Return, Esc | Move, run and close in the actions palette |
| Return | The main button of a sheet (**Connect**, **Save**, **Create**, **Add**, **Apply**) |
| Esc | Cancel a sheet |

## On the Mac

<!-- only: linux windows -->

On Linux and Windows the commands below are the same, in the **Shell** and **Data** menus, with Ctrl for ⌘, Alt for
⌥, Shift for ⇧ and the Windows (Super) key for ⌃. For example, **New Local Terminal** is Ctrl+N and **Run** is
Ctrl+Return. **Settings…** (Ctrl+,) is in the **Shell** menu, and Esc closes Settings.

<!-- /only -->

### Shell menu

| Keys | Command |
|---|---|
| ⌘N | **New Local Terminal**. With something selected, a new one of the same kind: **New Connection to …**, **New Persistent Session**, **New Web Page**, **New Note** or **Open …** for a database |
| ⌘T | **New Terminal in Same Directory** |
| ⇧⌘N | **New Persistent Session** |
| ⌘R | **Actions…** (the actions palette) |
| ⇧⌘R | **Create Action from Session** |
| ⌘E | **Insert into Terminal…** |
| ⇧⌘D | **Detach Session/Note** (again to bring it back) |
| ⇧⌘H | **Appearance…** |
| ⇧⌘F | **Toggle Files Panel** |
| ⇧⌘U | **Navigate Up** in the Files panel |
| ⌘W | **Close Terminal**, **Close Connection**, **Close Session**, **Close Action**, **Close Database**, **Close Note** and so on, for the selected item |
| ⇧⌘C | **Copy SSH Public Key** |

A command whose feature is off in **Settings ▸ Features** is left out of the menu, along with its shortcut.

<!-- only: mac -->

On the Mac, ⌘W never closes the main window, and **Settings…** (⌘,) is in the **Shell** app menu.

<!-- /only -->

### Data menu

With **Database** on, the **Data** menu has Database's commands for the open database:

| Keys | Command |
|---|---|
| ⌥⌘T | **New Query** |
| ⌥⌘R | **Refresh** |
| ⌘Return | **Run** |
| ⇧⌘E | **Show Query Editor** / **Hide Query Editor** |
| ⌘S | **Review Changes…** |
| ⌥⌘I | **Show Inspector** |
| ⌥⇧⌘Z | **Undo Last Save** (in the **Edit** menu) |

<!-- only: mac -->

### In a terminal

| Keys | What it does |
|---|---|
| ⌘C | Copy the selection, or the visible screen when nothing is selected |
| ⌘V | Paste |
| ⌘K | Clear the scrollback |

Every other key, with Control and Option, goes to the program in the terminal.

### Accounts

⌃⌘1 to ⌃⌘9 switch to the first to ninth account.

<!-- /only -->

<!-- only: linux windows -->

### In a terminal

| Keys | What it does |
|---|---|
| Ctrl+Shift+C | Copy the selection, or the visible screen when nothing is selected |
| Ctrl+Shift+V | Paste |
| Ctrl+Shift+K | Clear the scrollback |

Ctrl with any other key, and Alt, go to the program in the terminal, as in other terminals: Ctrl+C interrupts it.
On Windows, as in Windows Terminal, Ctrl+V pastes too, and Ctrl+C copies while text is selected.

<!-- /only -->

## On iPhone and iPad

### With a keyboard on iPad

| Keys | What it does |
|---|---|
| ⌘C | In a terminal: copy the selection, or the visible screen when nothing is selected |
| ⌘V | In a terminal: paste |
| ⌘K | In a terminal: clear the scrollback |
| ⌃⌘1 … ⌃⌘9 | Switch to the first to ninth account |

In a terminal, every other key, with Control and Option, goes to the program. Esc also closes Settings.
